# Banking Management System

A simple menu-driven Banking Management System developed using C programming.

## Features
- Create a bank account
- Deposit money
- Withdraw money
- Check account balance
- View account details
- Save account information using file handling
- Load saved account information when the program restarts

## Technologies Used
- C Programming
- File Handling
- Standard C Libraries

## How to Run

1. Download or clone this repository.
2. Open the project folder in your terminal.
3. Compile the program:

```bash
gcc banking.c -o banking
```

4. Run the program:

```bash
./banking
```

## What I Learned

Through this project, I practised C programming concepts such as conditional statements, loops, switch statements, functions of file handling, and input/output operations.
